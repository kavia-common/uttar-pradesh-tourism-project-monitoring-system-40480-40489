# UPSTDC Database (PostgreSQL)

This folder contains PostgreSQL migrations, seed data, and scripts for setup, backup, and restore.

Default environment (can be overridden):
- POSTGRES_HOST=localhost
- POSTGRES_PORT=5001
- POSTGRES_DB=myapp
- POSTGRES_USER=appuser
- POSTGRES_PASSWORD=dbuser123
- POSTGIS_ENABLE=false

Quick start

1) Start/ensure PostgreSQL running on the desired port (5001)
- If using the provided startup script on a host with PostgreSQL binaries:
  POSTGRES_PORT=5001 POSTGIS_ENABLE=false bash startup.sh
- This will:
  - Ensure the DB/user exist
  - Run migrations idempotently (0001..0005)
  - Write connection info to db_connection.txt
  - Write db_visualizer/postgres.env

2) Run migrations (idempotent)
- POSTGRES_PORT=5001 bash migrate.sh

3) Connect
- See db_connection.txt (generated by startup.sh) or:
  psql postgresql://appuser:dbuser123@localhost:5001/myapp

4) Seeded data
- 0005_seed.sql creates departments and demo data.
- Admin user in seed uses placeholder hash. Prefer creating users via backend /api/auth/signup.

Run checklist (for full app)

- Ensure DB is running on port 5001
- Run migrations (migrate.sh)
- Copy connection string into backend .env as DATABASE_URL
- Start backend, then frontend
- Verify CRUD from frontend persists into the database
